# Specyfikacja projektu

Projekt: Przenośna stacja meteorologiczna

## Pomiary
Co mierzymy:
- Temperatura
- Ciśnienie
- Wilgotność
- PM1.0
- PM2.5
- PM10
- O3 (ozon)
- NO2 (jakościowo, nie ilościowo)
- Poziom światła
- GPS

## Zasilanie
Stacja musi być zasilana wewnętrznie, aby była przenośna. Potrzebne będą baterie/ogniwa/powerbank. Stacja powinna być w stanie pracować przez około miesiąc.

## Obudowa
Moduły muszą być chronione przed warunki atmosferyczne, ale do czujników musi być dostęp powietrza. Obudowa będzie wydrukowana 3D, jako klatka Stevensona. Sensory i moduły muszą nie być narażone na deszcz lub promienie słoneczne.
